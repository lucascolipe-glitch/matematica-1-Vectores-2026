Qué es un vector

Un segmento orientado tiene punto inicial, punto final, módulo, dirección y sentido.

Magnitud escalar

Un número y una unidad

Temperatura, masa, tiempo, área o volumen quedan caracterizados por un valor real.

Magnitud vectorial

Magnitud + dirección + sentido

Fuerza, velocidad y desplazamiento necesitan información sobre cuánto y hacia dónde.

Definición

Llamamos vector a un segmento orientado \(\overrightarrow{PQ}\), donde \(P\) es el punto inicial y \(Q\) el punto final.

Módulo
Longitud del segmento: \(\|\overrightarrow{PQ}\|\).
Dirección
La recta de acción que contiene al vector, o cualquier recta paralela.
Sentido
La orientación desde el punto inicial hacia el punto final.
Vectores equivalentes. Dos vectores son equivalentes cuando tienen el mismo módulo, dirección y sentido. En coordenadas, esto equivale a tener las mismas componentes.

2

Componentes, módulo y distancia

Las componentes se obtienen como punto final menos punto inicial.

Componentes

Si \(P=(p_1,p_2)\) y \(Q=(q_1,q_2)\), entonces

\[\overrightarrow{PQ}=(q_1-p_1,\,q_2-p_2).\]

Módulo

Para \(\vec v=(a,b)\):

\[\|\vec v\|=\sqrt{a^2+b^2}.\]

Distancia

La distancia entre \(P\) y \(Q\) coincide con el módulo de \(\overrightarrow{PQ}\).

\[d(P,Q)=\sqrt{(q_1-p_1)^2+(q_2-p_2)^2}.\]

Laboratorio gráfico

Mové los puntos inicial y final

El vector no se calcula con las coordenadas aisladas: siempre se resta \(Q-P\).

¿Cómo hallar un punto final?

Si conocemos el punto inicial \(P\) y las componentes \(\vec v=(a,b)\), el punto final se obtiene sumando: \(Q=P+\vec v=(p_1+a,p_2+b)\).

3

Operaciones con vectores

La suma y la multiplicación por un escalar se realizan componente a componente.

Suma

Si \(\vec u=(a,b)\) y \(\vec v=(c,d)\),

\[\vec u+\vec v=(a+c,b+d).\]

Multiplicación por un escalar

Para \(k\in\mathbb R\),

\[k\vec u=(ka,kb).\]

Método del triángulo

Trasladamos \(\vec v\) para que comience donde termina \(\vec u\). La suma une el origen del primero con el extremo del segundo.

Método del paralelogramo

Con ambos vectores en el mismo origen, completamos un paralelogramo. La diagonal es \(\vec u+\vec v\).

Explorador de operaciones

Suma y producto por escalar

Interpretación de \(k\vec v\). Si \(k\gt0\), conserva el sentido; si \(k\lt0\), lo invierte. Si \(|k|\gt1\), dilata; si \(0\lt|k|\lt1\), contrae.

4

Paralelismo, dirección y versores

Los múltiplos escalares comparten dirección; el signo del escalar determina el sentido.

Vectores paralelos

\(\vec u\parallel\vec v\) si existe \(k\in\mathbb R\setminus\{0\}\) tal que \(\vec u=k\vec v\).

Versor

Un vector unitario tiene módulo 1. Para \(\vec v\ne\vec0\):

\[\widehat v=\frac{1}{\|\vec v\|}\vec v.\]

Versores canónicos

\(\hat\imath=(1,0)\) y \(\hat\jmath=(0,1)\). Todo vector \((a,b)\) se escribe \(a\hat\imath+b\hat\jmath\).

\(k\gt0\)

Misma dirección y mismo sentido.

\(k\lt0\)

Misma dirección y sentido contrario.

Producto escalar, ángulo y ortogonalidad

El producto escalar traduce una relación geométrica en un número real.

Por componentes

Para \(\vec u=(u_1,u_2)\), \(\vec v=(v_1,v_2)\):

\[\vec u\cdot\vec v=u_1v_1+u_2v_2.\]

Con el ángulo

Para vectores no nulos:

\[\vec u\cdot\vec v=\|\vec u\|\,\|\vec v\|\cos\theta.\]

\[\theta=\arccos\left(\frac{\vec u\cdot\vec v}{\|\vec u\|\|\vec v\|}\right).\]

\(\vec u\cdot\vec v\gt0\)Ángulo agudo
\(\vec u\cdot\vec v=0\)Vectores ortogonales
\(\vec u\cdot\vec v\lt0\)Ángulo obtuso

Descomposición en dos direcciones

Buscamos escalares \(k_1\) y \(k_2\) tales que \(\vec q=k_1\vec a+k_2\vec b\).

Idea central

Una combinación lineal

Al igualar las componentes se obtiene un sistema de dos ecuaciones. Si \(\vec a\) y \(\vec b\) no son paralelos, la descomposición existe y es única.

\[\vec q=k_1\vec a+k_2\vec b.\]

  1. Escribir los tres vectores por componentes.
  2. Multiplicar \(k_1\vec a\) y \(k_2\vec b\).
  3. Igualar primera y segunda componente.
  4. Resolver el sistema y verificar.

Barcos y faro
