# Matemática 1 · Unidad 3: Vectores

Sitio teórico-práctico interactivo para la Unidad 3 de Matemática 1 (FaCiAS · UNCo), preparado para publicar en GitHub Pages.

## Contenidos

- Magnitudes escalares y vectoriales.
- Definición de vector: módulo, dirección y sentido.
- Vectores equivalentes.
- Componentes, módulo y distancia entre puntos.
- Suma y multiplicación por un escalar.
- Métodos del triángulo y del paralelogramo.
- Paralelismo, versores y versores canónicos.
- Producto escalar, ángulo y ortogonalidad.
- Descomposición en dos direcciones.
- Aplicaciones del TP 2026: flujo superficial, barcos y faro, fuerzas y cintas transportadoras.

## Interactividad

- Una sola sección visible por vez.
- Laboratorios SVG para puntos, vectores, operaciones, ángulo y descomposición, con escala 1:1 y grilla que se ajusta automáticamente.
- Actividades con tarjetas seleccionables y fórmulas MathJax.
- Devolución inmediata y guardado local del progreso.
- Práctica integradora aleatoria.
- Diseño responsive e impresión completa.

## Publicación en GitHub Pages

1. Subir `index.html`, `css/` y `js/` a la raíz del repositorio.
2. Ir a **Settings → Pages**.
3. Elegir la rama `main` y la carpeta `/ (root)`.
4. Guardar y esperar la publicación.

## Criterio de edición de las fuentes

El contenido mantiene la organización y terminología de los apuntes y del trabajo práctico. Para evitar trasladar errores a la página, se normalizaron únicamente erratas algebraicas o tipográficas evidentes mediante verificación directa de las cuentas; por ejemplo, al reconstruir un punto final se usó coherentemente `Q = P + v`.
